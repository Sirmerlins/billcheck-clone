BillPay 146 — PHP Version
=========================

Upload Instructions:
1. Extract this ZIP file.
2. Upload all files and folders (index.php, api.php, styles.css, app.js, data/)
   into your web hosting directory (e.g. public_html/ or public_html/billpay/).
3. Ensure the "data/" folder and "data/paid.json" are writable by PHP
   (typically permissions 755 or 775 for data/, and 644 or 664 for data/paid.json).
4. Open the URL in your browser (requires PHP 7.4 or newer; no database needed).
